nvme-memblaze-smart-log-add(1)
==============================

NAME
----
nvme-memblaze-smart-log-add - Retrieve Memblaze SMART Log, show it

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'memblaze smart-log-add' <device>
			[--namespace-id=<num> | -n <num>]
			[--raw-binary | -b]

DESCRIPTION
-----------
Retrieve Memblaze SMART Log, show it.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).

This page only lists the help texts of the command. A detailed
description is still missing.

OPTIONS
-------
-n <num>::
--namespace-id=<num>::
	(optional) desired namespace
+
Values: 'all', '-1'.

-b::
--raw-binary::
	dump output in binary format
