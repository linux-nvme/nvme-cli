nvme-ibm-persist-event-log(1)
=============================

NAME
----
nvme-ibm-persist-event-log - IBM specific Persistent Event Log

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'ibm persist-event-log' <device>
			[--action=<num> | -a <num>]
			[--log_len=<num> | -l <num>]
			[--raw-binary | -b]

DESCRIPTION
-----------
IBM specific Persistent Event Log.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).

This page only lists the help texts of the command. A detailed
description is still missing.

OPTIONS
-------
-a <num>::
--action=<num>::
	action the controller shall take during processing this persistent log page command.

-l <num>::
--log_len=<num>::
	number of bytes to retrieve

-b::
--raw-binary::
	use binary output
