NAME
----
nvme-memblaze-perf-stats-print-x - Get Performance Stat log and show it.

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'memblaze perf-stats-print-x' <device>
			[--duration=<num> | -d <num>]
			[--raw-binary | -b]

DESCRIPTION
-----------
Get Performance Stat log and show it.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).

This page only lists the help texts of the command. A detailed
description is still missing.

OPTIONS
-------
-d <num>::
--duration=<num>::
	[1-24] hours: duration of the log to print, default 1 hour

-b::
--raw-binary::
	dump the whole log buffer in binary format
