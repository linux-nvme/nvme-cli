nvme-sfx-status(1)
==================

NAME
----
nvme-sfx-status - Retrieve the ScaleFlux status output, show it

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'sfx status' <device>
			[--json-print | -j]

DESCRIPTION
-----------
Retrieve the ScaleFlux status output, show it.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).
