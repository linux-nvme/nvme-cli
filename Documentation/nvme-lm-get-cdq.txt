nvme-lm-get-cdq(1)

NAME
----
nvme-lm-get-cdq - Get Feature - Controller Data Queue (FID 21h)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'lm get-cdq' <device>
			[--cdqid=<num> | -C <num>]

DESCRIPTION
-----------
Get Feature - Controller Data Queue (FID 21h).

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).

This page only lists the help texts of the command. A detailed
description is still missing.

OPTIONS
-------
-C <num>::
--cdqid=<num>::
	Controller Data Queue ID
