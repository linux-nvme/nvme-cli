nvme-detach-ns(1)
=================

NAME
----
nvme-detach-ns - Send NVMe detach namespace, return result. (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'detach-ns' <device>
			[--namespace-id=<nsid> | -n <nsid>]
			[--controllers=<ctrl-list,> | -c <ctrl-list,>]

DESCRIPTION
-----------
Deprecated alias for linknvme-ns-detach[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme ns detach' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme-ns-detach[1] for the full option reference.
