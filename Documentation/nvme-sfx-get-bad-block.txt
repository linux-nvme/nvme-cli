nvme-sfx-get-bad-block(1)
=========================

NAME
----
nvme-sfx-get-bad-block - Retrieve bad block table of block device, show it

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'sfx get-bad-block' <device>

DESCRIPTION
-----------
Retrieve bad block table of block device, show it.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).
