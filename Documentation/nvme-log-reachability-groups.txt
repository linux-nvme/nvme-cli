nvme-log-reachability-groups(1)
===============================

NAME
----
nvme-log-reachability-groups - Retrieve Reachability Groups Log, show it

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'log reachability-groups' <device>
			[--groups-only | -g]
			[--rae | -r]

DESCRIPTION
-----------
Retrieve Reachability Groups Log, show it

The <device> parameter is mandatory NVMe character device (ex: /dev/nvme0).

On success it returns 0, error code otherwise.

OPTIONS
-------
-g::
--groups-only::
	Return Groups Only.

-r::
--rae::
	Retain an Asynchronous Event.

include::global-options.txt[]

EXAMPLES
--------
* Has the program issue a reachability-groups-log
+
------------
# nvme log reachability-groups /dev/nvme0
------------

NVME
----
Part of the nvme-user suite.
