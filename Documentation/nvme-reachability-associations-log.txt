nvme-reachability-associations-log(1)
=====================================

NAME
----
nvme-reachability-associations-log - Retrieve Reachability Associations Log, show it (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'reachability-associations-log' <device>
			[--associations-only | -a]
			[--rae | -r]

DESCRIPTION
-----------
Deprecated alias for linknvme:nvme-log-reachability-associations[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme log reachability-associations' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme:nvme-log-reachability-associations[1] for the full option reference.
