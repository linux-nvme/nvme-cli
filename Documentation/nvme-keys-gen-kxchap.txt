nvme-keys-gen-kxchap(1)
=======================

NAME
----
nvme-keys-gen-kxchap - Generate a host KX-HMAC-CHAP secret

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'keys gen-kxchap' [--hmac=<hmac-id> | -m <hmac-id>]
			[--secret=<secret> | -s <secret>]
			[--key-length=<len> | -l <len>]

DESCRIPTION
-----------
Generate a KX-HMAC-CHAP secret in the DHHC-1 secret representation defined by
the NVM Express Base Specification 2.4, section 8.3.4.5.8, in the form:
DHHC-1:00:ia6zGodOr4SEG0Zzaw398rpY0wqipUWj4jWjUh4HWUz6aQ2n:
and prints it to stdout.

OPTIONS
-------
-m <hmac-id>::
--hmac=<hmac-id>::
	Select the hash function the consumer is to apply to the secret.
	Possible values are:
	0 - No transformation (the secret is used as the key)
	1 - SHA-256
	2 - SHA-384
	3 - SHA-512

-s <secret>::
--secret=<secret>::
	Secret value (in hexadecimal) to be placed in the representation. If
	none are provided a random value is used.

-l <len>::
--key-length=<len>::
	Length of the secret. Possible values are 32, 48, or 64. A secret
	given with '--secret' as hexadecimal fixes the length, so a value
	contradicting it is an error; a secret generated here takes this
	length, defaulting to the digest size of the selected hash
	function, or 32 if none is selected.
