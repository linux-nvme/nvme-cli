nvme-ibm-crit-log(1)
====================

NAME
----
nvme-ibm-crit-log - Display IBM Smart Log Information

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'ibm crit-log' <device>
			[--raw-binary | -b]

DESCRIPTION
-----------
Display IBM Smart Log Information.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).

description is still missing.
