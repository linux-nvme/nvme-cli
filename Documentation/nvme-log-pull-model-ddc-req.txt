nvme-log-pull-model-ddc-req(1)
==============================

NAME
----
nvme-log-pull-model-ddc-req - Retrieve Pull Model DDC Request Log, show it

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'log pull-model-ddc-req' <device>
			[--rae | -r]

DESCRIPTION
-----------
Retrieve Pull Model DDC Request Log, show it.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).
