nvme-ana-log(1)
===============

NAME
----
nvme-ana-log - Send NVMe ANA log page request, returns result and log (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'ana-log' <device> [--groups | -g]

DESCRIPTION
-----------
Deprecated alias for linknvme-log-ana[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme log ana' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme-log-ana[1] for the full option reference.
