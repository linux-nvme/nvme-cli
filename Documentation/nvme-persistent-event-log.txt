nvme-persistent-event-log(1)
============================

NAME
----
nvme-persistent-event-log - Send NVMe persistent event log page request,
returns result and log (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'persistent-event-log' <device>
			[--action=<action> | -a <action>]
			[--log-len=<log-len> | -l <log-len>]
			[--raw-binary | -b]

DESCRIPTION
-----------
Deprecated alias for linknvme:nvme-log-persistent-event[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme log persistent-event' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme:nvme-log-persistent-event[1] for the full option reference.
