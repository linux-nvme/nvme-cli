nvme-supported-log-pages(1)
===========================

NAME
----
nvme-supported-log-pages - Send NVMe Supported Log pages request, returns result and log (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'supported-log-pages' <device>

DESCRIPTION
-----------
Deprecated alias for linknvme:nvme-log-supported-pages[1], kept for scripts
written against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme log supported-pages' instead. This alias prints
a deprecation warning on stderr and may be removed in a future release.

See linknvme:nvme-log-supported-pages[1] for the full option reference.
