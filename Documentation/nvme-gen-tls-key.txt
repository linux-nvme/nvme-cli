nvme-gen-tls-key(1)
===================

NAME
----
nvme-gen-tls-key - Generate a NVMe TLS PSK (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'gen-tls-key' [--keyring=<name> | -k <name>]
			[--keytype=<type> | -t <type>]
			[--hostnqn=<nqn> | -n <nqn>]
			[--subsysnqn=<nqn> | -c <nqn>]
			[--hmac=<hmac-id>]
			[--identity=<id-vers> | -I <id-vers>]
			[--secret=<secret> | -s <secret>]
			[--insert | -i]
			[--compat | -C]
			[--keyfile=<keyfile> | -f <keyfile>]

DESCRIPTION
-----------
Deprecated alias for linknvme-keys-gen-tls[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical, with one exception: the short form of '--hmac' changed from
'-h' to '-m' when key generation moved into the 'keys' plugin, because
'-h' now collides with the global '--help' flag. Scripts using the short
'-h <hmac-id>' form must switch to '-m <hmac-id>' or '--hmac=<hmac-id>';
all other options, including the long form '--hmac=', continue to work
unchanged through this alias.

New scripts should use 'nvme keys gen-tls' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme-keys-gen-tls[1] for the full option reference.
