nvme-ocp-set-enable-ieee1667-silo(1)
====================================

NAME
----
nvme-ocp-set-enable-ieee1667-silo - Set Enable IEEE1667 Silo Feature

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'ocp set-enable-ieee1667-silo' <device>
			[--enable | -e]
			[--save | -s]
			[--no-uuid | -n]

DESCRIPTION
-----------
Set Enable IEEE1667 Silo Feature.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).

This page only lists the help texts of the command. A detailed
description is still missing.

OPTIONS
-------
-e::
--enable::
	enable the silo, disable it if not given

-s::
--save::
	Specifies that the controller shall save the attribute

-n::
--no-uuid::
	Skip UUID index search (UUID index not required for OCP 1.0)
