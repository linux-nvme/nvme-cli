nvme-primary-ctrl-caps(1)
=========================

NAME
----
nvme-primary-ctrl-caps - Send identify Primary Controller Caps, return result and structure (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'primary-ctrl-caps' <device>

DESCRIPTION
-----------
Deprecated alias for linknvme:nvme-id-primary-ctrl-caps[1], kept for scripts
written against nvme-cli versions older than 3.0. Options and behavior
are identical; only the top-level command name is retained.

New scripts should use 'nvme id primary-ctrl-caps' instead. This alias
prints a deprecation warning on stderr and may be removed in a future
release.

See linknvme:nvme-id-primary-ctrl-caps[1] for the full option reference.
