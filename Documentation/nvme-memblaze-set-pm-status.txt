nvme-memblaze-set-pm-status(1)
==============================

NAME
----
nvme-memblaze-set-pm-status - Set Memblaze Power Manager Status

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'memblaze set-pm-status' <device>
			[--value=<num> | -V <num>]
			[--save | -s]

DESCRIPTION
-----------
Set Memblaze Power Manager Status.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).

This page only lists the help texts of the command. A detailed
description is still missing.

OPTIONS
-------
-V <num>::
--value=<num>::
	new value of feature (required)

-s::
--save::
	specifies that the controller shall save the attribute
