nvme-memblaze-clear-error-log(1)
================================

NAME
----
nvme-memblaze-clear-error-log - Clear error log

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'memblaze clear-error-log' <device>

DESCRIPTION
-----------
Clear error log.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).
