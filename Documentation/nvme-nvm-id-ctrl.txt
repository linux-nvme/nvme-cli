nvme-nvm-id-ctrl(1)
===================

NAME
----
nvme-nvm-id-ctrl - Send NVMe Identify Controller, return NVM command set structure (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'nvm-id-ctrl' <device>

DESCRIPTION
-----------
Deprecated alias for linknvme:nvme-id-nvm-ctrl[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme id nvm-ctrl' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme:nvme-id-nvm-ctrl[1] for the full option reference.
