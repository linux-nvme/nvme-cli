nvme-phy-rx-eom-log(1)
======================

NAME
----
nvme-phy-rx-eom-log - Retrieves a Physical Interface Receiver Eye Opening
Measurement log page from an NVMe device (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'phy-rx-eom-log' <device> [--lsp=<field> | -s <field>]
			[--controller=<id> | -c <id>]

DESCRIPTION
-----------
Deprecated alias for linknvme:nvme-log-phy-rx-eom[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme log phy-rx-eom' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme:nvme-log-phy-rx-eom[1] for the full option reference.
