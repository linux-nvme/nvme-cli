nvme-memblaze-lat-log(1)
========================

NAME
----
nvme-memblaze-lat-log - Set Memblaze High Latency Log

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'memblaze lat-log' <device>
			[--param=<list> | -p <list>]

DESCRIPTION
-----------
Set Memblaze High Latency Log.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).
