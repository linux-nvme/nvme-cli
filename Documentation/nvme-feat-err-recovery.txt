nvme-feat-err-recovery(1)
=========================

NAME
----
nvme-feat-err-recovery - Get and set error recovery feature

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'feat err-recovery' <device>
			[--nsid=<nsid> | -n <nsid>]
			[--tler=<tler> | -t <tler>]
			[--dulbe | -d]
			[--sel=<select> | -S <select>] [--save | -s]

DESCRIPTION
-----------
Get and set the error recovery feature.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).
If the character device is given, the `'--nsid'` option is mandatory, otherwise
it will use the ns-id of the namespace for the block device you opened.
For block devices, the ns-id used can be overridden with the same option.

If any of the setting options (`--tler` or `--dulbe`) are specified, the
command will update the error recovery configuration for the specified
namespace. If neither option is specified, it will retrieve and display
the current configuration.

On success it returns 0, error code otherwise.

OPTIONS
-------
-n <nsid>::
--nsid=<nsid>::
	Sends the command with the requested nsid. This is required for the
	character devices, or overrides the block nsid if given.

-t <tler>::
--tler=<tler>::
	Time limited error recovery value. Indicaes the limited retry time
	in 100 millisecond units.

-d::
--dulbe::
	Deallocated or unwritten logical block error enable.

-S <select>::
--sel=<select>::
	Select (SEL): This field specifies which value of the attributes
	to return in the provided data:

-s::
--save::
	Save the attribute so that it persists through all power states and resets.

include::global-options.txt[]

EXAMPLES
--------
* Has the program issue a feat err-recovery to get the current configuration:
+
------------
# nvme feat err-recovery /dev/nvme0n1
------------

* Has the program issue a feat err-recovery to set tler and dulbe parameters:
+
------------
# nvme feat err-recovery /dev/nvme0n1 --tler=10 --dulbe
------------
