nvme-predictable-lat-log(1)
===========================

NAME
----
nvme-predictable-lat-log - Send Predictable latency per NVM set log page request,
returns result and log (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'predictable-lat-log' <device>
			[--nvmset-id=<nvmset_id> | -i <nvmset_id>]
			[--raw-binary | -b]

DESCRIPTION
-----------
Deprecated alias for linknvme-log-predictable-lat[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme log predictable-lat' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme-log-predictable-lat[1] for the full option reference.
