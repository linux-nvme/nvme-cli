nvme-delete-ns(1)
=================

NAME
----
nvme-delete-ns - Send NVMe Namespace Management delete namespace command, return result. (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'delete-ns' <device>
			[--namespace-id=<nsid> | -n <nsid>]

DESCRIPTION
-----------
Deprecated alias for linknvme:nvme-ns-delete[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme ns delete' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme:nvme-ns-delete[1] for the full option reference.
