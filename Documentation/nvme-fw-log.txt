nvme-fw-log(1)
==============

NAME
----
nvme-fw-log - Send NVMe Firmware log page request, returns result and log (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'fw-log' <device> [--raw-binary | -b]

DESCRIPTION
-----------
Deprecated alias for linknvme-log-fw[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme log fw' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme-log-fw[1] for the full option reference.
