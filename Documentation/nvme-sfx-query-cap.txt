nvme-sfx-query-cap(1)
=====================

NAME
----
nvme-sfx-query-cap - Query current capacity info

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'sfx query-cap' <device>
			[--raw-binary | -b]

DESCRIPTION
-----------
Query current capacity info.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).

description is still missing.
