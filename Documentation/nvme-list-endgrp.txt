nvme-list-endgrp(1)
===================

NAME
----
nvme-list-endgrp - Send NVMe Identify Endurance Group List, return result and
structure (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'list-endgrp' <device>
			[--endgrp-id=<endgrp-id> | -i <endgrp-id>]

DESCRIPTION
-----------
Deprecated alias for linknvme-id-endgrp-list[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme id endgrp-list' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme-id-endgrp-list[1] for the full option reference.
