nvme-resv-notif-log(1)
======================

NAME
----
nvme-resv-notif-log - Send NVMe Reservation Notification log page request,
return result and log (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'resv-notif-log' <device>

DESCRIPTION
-----------
Deprecated alias for linknvme-log-resv-notif[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme log resv-notif' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme-log-resv-notif[1] for the full option reference.
