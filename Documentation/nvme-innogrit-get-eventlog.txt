nvme-innogrit-get-eventlog(1)
=============================

NAME
----
nvme-innogrit-get-eventlog - get event log

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'innogrit get-eventlog' <device>

DESCRIPTION
-----------
Get event log.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).
