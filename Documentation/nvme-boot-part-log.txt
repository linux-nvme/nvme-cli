nvme-boot-part-log(1)
=====================

NAME
----
nvme-boot-part-log - Retrieves a Boot Partition log page from an NVMe device (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'boot-part-log' <device> [--lsp=<field> | -s <field>]
			[--output-file=<file> | -f <file>]

DESCRIPTION
-----------
Deprecated alias for linknvme-log-boot-part[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme log boot-part' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme-log-boot-part[1] for the full option reference.
