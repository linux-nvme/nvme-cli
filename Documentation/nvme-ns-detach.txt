nvme-ns-detach(1)
=================

NAME
----
nvme-ns-detach - Send NVMe detach namespace, return result.

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'ns detach' <device>
			[--namespace-id=<nsid> | -n <nsid>]
			[--controllers=<ctrl-list,> | -c <ctrl-list,>]

DESCRIPTION
-----------
For the NVMe device given, sends the nvme namespace detach command for
the provided namespace identifier, detaching to the provided list of
controller identifiers.

OPTIONS
-------
-n <nsid>::
--namespace-id=<nsid>::
	The namespace identifier to detach.

-c <ctrl-list,>::
--controllers=<ctrl-list,>::
	The comma separated list of controller identifiers to detach
	the namespace from.
