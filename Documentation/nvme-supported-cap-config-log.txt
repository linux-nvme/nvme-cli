nvme-supported-cap-config-log(1)
================================

NAME
----
nvme-supported-cap-config-log - Send NVMe Supported Capacity
Configuration List Log pages request, returns result and log. (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'supported-cap-config-log' <device>
			[--dom-id | -d]
			[--raw-binary | -b]

DESCRIPTION
-----------
Deprecated alias for linknvme:nvme-log-supported-cap-config[1], kept for scripts written
against nvme-cli versions older than 3.0. Options and behavior are
identical; only the top-level command name is retained.

New scripts should use 'nvme log supported-cap-config' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme:nvme-log-supported-cap-config[1] for the full option reference.
