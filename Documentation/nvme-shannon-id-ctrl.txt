nvme-shannon-id-ctrl(1)
=======================

NAME
----
nvme-shannon-id-ctrl - Retrieve Shannon ctrl id, show it

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'shannon id-ctrl' <device>
			[--vendor-specific | -V]
			[--raw-binary | -b]

DESCRIPTION
-----------
Retrieve Shannon ctrl id, show it.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).

This page only lists the help texts of the command. A detailed
description is still missing.

OPTIONS
-------
-V::
--vendor-specific::
	dump binary vendor field

-b::
--raw-binary::
	show identify in binary format
