nvme-memblaze-lat-stats-print(1)
================================

NAME
----
nvme-memblaze-lat-stats-print - Retrieve IO Latency Statistics log, show it

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'memblaze lat-stats-print' <device>
			[--write | -w]

DESCRIPTION
-----------
Retrieve IO Latency Statistics log, show it.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).
