nvme-sfx-lat-stats(1)
=====================

NAME
----
nvme-sfx-lat-stats - Retrieve ScaleFlux IO Latency Statistics log, show it

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'sfx lat-stats' <device>
			[--write | -w]
			[--raw-binary | -b]

DESCRIPTION
-----------
Retrieve ScaleFlux IO Latency Statistics log, show it.

The <device> parameter is mandatory and may be either the NVMe character
device (ex: /dev/nvme0), or a namespace block device (ex: /dev/nvme0n1).

This page only lists the help texts of the command. A detailed
description is still missing.

OPTIONS
-------
-w::
--write::
	Get write statistics (read default)

-b::
--raw-binary::
	dump output in binary format
