nvme-gen-dhchap-key(1)
======================

NAME
----
nvme-gen-dhchap-key - Generate a host DH-HMAC-CHAP secret (deprecated)

SYNOPSIS
--------
[verse]
'nvme' [<global-options>] 'gen-dhchap-key' [--hmac=<hmac-id> | -m <hmac-id>]
			[--secret=<secret> | -s <secret>]
			[--key-length=<len> | -l <len>]
			[--nqn=<host-nqn> | -n <host-nqn>]

DESCRIPTION
-----------
Deprecated alias for linknvme-keys-gen-kxchap[1], kept for scripts written
against nvme-cli versions older than 3.0. It forwards to that command, with
two differences from nvme-cli 2.x:

* '--nqn'/'-n' is accepted and ignored, with a warning.
* '--secret'/'-s' goes into the DHHC-1 string as it stands, where 2.x put the
  key transformed from it, so the output differs whenever '--hmac' is
  non-zero.

New scripts should use 'nvme keys gen-kxchap' instead. This alias prints a
deprecation warning on stderr and may be removed in a future release.

See linknvme-keys-gen-kxchap[1] for the full option reference.
